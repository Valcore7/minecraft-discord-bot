# Minecraft Bedrock Server Discord Bot

A Discord bot that monitors a Minecraft Bedrock server hosted via WitherHosting and reports:

- Server status (online/offline)
- Player count
- Backup notifications
- Bedrock ping
- Slash commands to view status, players, IP, and backup time

## 🧰 Features

- Real-time notifications for server events
- Slash command support:
  - `/status`
  - `/backup`
  - `/players`
  - `/ip`
- Bot presence shows live player count
